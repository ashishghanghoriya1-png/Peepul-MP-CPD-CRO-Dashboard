# Peepul MP CPD 2025-26 Executive CRO Intelligence Platform

An interactive Streamlit analytics platform for state-level monitoring and diagnostic intelligence on Classroom Observation (CRO) data across primary schools in Madhya Pradesh.

## 🚀 Key Features
- **State Academic Health Index Scorecard (48.1 / 100 Baseline)**: Dynamic empirical health scoring across 5 core pillars.
- **TabFM AI Engine**: Zero-shot feature interaction modeling, pedagogy alignment disconnect scorecard, and predictive competency risk simulation.
- **District Risk Scorecard**: Benchmarking district performance with risk-tier color coding.
- **Student Competency Progression Funnel**: Step-by-step retention modeling from enrollment down to comprehension and writing mastery.
- **Teacher PD Module Recommender**: Automated module prescription mapping observed classroom gaps to MP CPD training modules.
- **Classroom Coaching ROI Calculator**: Interactive policy modeling tool for state leadership.
- **Systematic Qualitative Intelligence**: Categorized observer field notes with keyword search and district filtering.

## 🛠️ Local Setup
```bash
pip install -r requirements.txt
streamlit run app.py
```
